# Allmiibo Manager v2.0.1

This maintenance release adds the legal and open-source documentation that
accompanies Allmiibo Manager and its Windows package.

## Changes

- License Allmiibo Manager under the MIT License.
- Document the licenses and source locations of bundled or build-time
  third-party components.
- Add a responsible-use notice for user-provided amiibo data.
- State clearly that users should only use data dumped from amiibo figures they
  physically own and must comply with applicable law.
- Attach the project license, third-party notices, and responsible-use notice to
  GitHub releases and local release builds.
- Add an automated check that the legal documents exist and are included in the
  release workflow.

There are no application behavior changes in this release.
